## Azure Virtual Desktop
![image_post0](/assets/images/AVD/1/AVD0.png)<br>
### ● 개념

▶ Azure에서 실행되는 데스크톱 및 애플리케이션 가상화 서비스

 ∘ 주요 기능

1. windows11, windows10 또는 windows server 를 사용해 환경 제공

2. Windows App 또는 RemoteApp 을 사용해 개별 앱 제공

3. 개인 데스크톱을 통해 개인 소유권 제공

4. 통합 관리 환경을 사용해 여러 Windows 및 Windows Server 운영 체제의 데스크톱 및 앱 관리 <br><br>

### ● 용어
#### ∘ 호스트풀
\- 세션 호스트로 Azure Virtual Desktop 에 등록된 Azure 가상 머신의 컬렉션<br>
\- 일관된 사용자 환경을 위해 호스트풀의 모든 세션 호스트 가상 머신을 동일한 이미지에서 원본으로 제공<br>
 ● 유형<br>
  1.개인<br>
   - 각 세션 호스트가 개별 사용자에게 할당<br>
   - 최대 세션 1명 제한<br>
   - 각 사용자는 각 VM의 OS 디스크에 사용자 프로필 데이터 저장 가능<br>
  2.풀링된<br>
   - 단일 세션 호스트에 동시에 여러 다른 사용자 존재 가능<br>
   - 최대 세션 제한 값으로 구성<br>
   - 연결할 때마다 다른 세션호스트에 연결되어 FSLogix에 사용자 프로필 데이터 저장<br><br>

#### ∘ 애플리케이션 그룹
\- 전체 데스크톱 또는 단일 호스트풀의 세션 호스트에서 사용할 수 있는 애플리케이션의 논리적 그룹화에 대한 액세스 제어 <br>
 ● 유형<br>
  1.데스크톱<br>
   - 사용자는 세션호스트에서 전체 Windows 데스크톱에 액세스<br>
   - 풀 또는 개인 호스트 풀에서 사용<br>
  2.RemoteApp<br>
   - 사용자가 선택한 개별 애플리케이션에 액세스하고 애플리케이션 그룹에 게시<br>
   - 풀된 호스트 풀에서만 사용 가능<br><br>

#### ∘ 작업 영역
\- 애플리케이션 그룹의 논리적 그룹화 <br>
\- 사용자가 게시된 데스크톱 및 애플리케이션을 보려면 각 애플리케이션 그룹을 작업영역과 연결 <br>
\- 단일 작업 영역에만 할당 가능 <br><br>

### ● 관리
#### ∘ 사용자 지정 RDP 속성 설정
\- 각 데스크톱 및 애플리케이션에 대해 RDP 를 통해 원격 세션 연결 시 사용할 모든 연결 속성을 포함하는 해당 .rdp 파일이 존재<br>
\- 해당 RDP 속성은 호스트 풀별로 설정 가능<br>
\- 각 호스트 풀의 기본 RDP 속성 및 집합에 다른 속성을 추가하거나 사용자 지정 RDP 속성을 설정해 기본값 재 정의 가능.<br>
#### ∘ 개인 데스크톱 할당 구성
\- 단일 사용자를 단일 개인 데스크톱에 할당<br>
\- 사용자가 로그인 시 사용자 세션은 할당된 개인 데스크톱 세션 호스트로 전달<br>
\- 사용자 활동, 파일 및 설정이 사용자가 로그아웃한 후 VM OS Disk 에 유지될 수 있다.<br>
#### ∘ 호스트풀 부하 분산 구성
\- 풀링된 호스트 풀에 대해 두 가지 부하 분산 알고리즘 지원<br>
\- 각 알고리즘은 사용자가 원격 세션을 시작할 때 사용되는 세션 호스트 결정<br>
 ● 알고리즘 유형<br>
  1.폭 우선<br>
   - 호스트 풀의 세션 호스트에 새 사용자 세션을 균등하게 배포<br>
   - 세션 수에 대한 최대 세션 제한 지정할 필요가 없음<br>
  2.깊이 우선<br>
   - 최대 세션 제한에 도달할 때까지 한 세션 호스트에서 새 사용자 세션을 계속 시작<br>
   - 세션 제한에 도달하면 새 사용자 연결은 세션 제한에 도달할 때까지 호스트 풀의 다음 세션 호스트로 전달<br><br>

### ∘ 보안
1. 화면 캡처 보호<br>
![image_post1](/assets/images/AVD/1/AVD1.png)<br>
\- 화면 캡처 보호를 사용하도록 설정 시 스크린샷 및 화면 공유에서 원격 콘텐츠가 자동으로 차단<br>
\- 화면 캡처 보호를 사용하도록 설정 시 Teams와 같이 로컬 공동 작업 소프트웨어를 사용해 원격 창 공유가 불가능<br><br>
2. 워터마킹<br>
![image_post2](/assets/images/AVD/1/AVD2.png)<br>
\- 중요한 정보가 클라이언트 엔드포인트에서 캡처되는 것을 방지<br>
\- 워터마크를 사용하도록 설정 시 QR 코드 워터마크가 원격 데스크톱의 일부로 표시<br>
\- QR코드에는 관리자가 세션을 추적하는 데 사용할 수 있는 원격 세션의 연결ID 또는 디바이스ID가 포함됨<br>

### ∘ 연결
\- Windows App 또는 원격 데스크톱 클라이언트를 사용해 Azure Virtual Desktop 에서 실행되는 Windows 데스크톱 및 앱에 원격으로 연결이 가능<br>
\- 웹 브라우저 및 가상 현실 헤드셋을 통해 데스크톱 및 노트북, 태블릿, 스마트폰과 같은 다양한 플랫폼 및 폼 팩터의 다양한 유형의 장치에서 사용 가능<br>
1. Windows App<br>
![image_post3](/assets/images/AVD/1/AVD3.png)<br>
\- Azure Virtual Desktop ,Windows 365 클라우드 PC, 원격 데스크톱 서비스 및 PC 에서 Windows 디바이스 및 앱에 원격으로 연결해 Windows 디바이스 및 앱에 안전하게 연결<br>
\- 데스크톱 및 노트북, 태블릿, 스마트폰 및 웹 브라우저와 같은 다양한 플랫폼 및 폼 팩터에 있는 다양한 유형의 디바이스에서 Windows 앱 사용 가능<br>
 ● 지원 플랫폼<br>
   - 윈도우즈<br>
   - macOS<br>
   - iOS/iPadOS<br>
   - Android/ChromeOS<br>
   - 웹브라우저<br>
 ● 기능<br>
   - 다중 모니터 지원<br>
   - 사용자 지정 디스플레이 해상도<br>
   - 동적 디스플레이 해상도 및 스케일링<br>
   - 웹캠, 오디어, 스토리지 디바이스 및 프린터와 같은 디바이스 리디렉션<br>
2. 원격 데스크톱 클라이언트<br>
![image_post4](/assets/images/AVD/1/AVD4.png)<br>
\- RDP를 이용해 네트워크 연결을 통해 원격 컴퓨터의 Windows 데스크톱 및 앱에 연결이 가능<br>
\- 독립 실행형 MSI 설치 프로그램으로 데스크톱, 노트북, 태블릿, 스마트폰 등 다양한 플랫폼과 폼팩터를 갖춘 여러 종류의 기기에서 웹 브라우저를 통해 사용 가능<br>
\- Windows App 으로 대체되어지는 중(2026년 3월 27일 부로 지원 중단 예정)<br>
\- WindowsApp 과 지원 플랫폼 및 기능은 동일함<br>

   - 윈도우즈<br>
   - macOS<br>
   - iOS/iPadOS<br>
   - Android/ChromeOS<br>
   - 웹브라우저<br>
 ● 기능<br>
   - 다중 모니터 지원<br>
   - 사용자 지정 디스플레이 해상도<br>
   - 동적 디스플레이 해상도 및 스케일링<br>
   - 웹캠, 오디어, 스토리지 디바이스 및 프린터와 같은 디바이스 리디렉션<br>
